# Cybersecurity Engineering Portfolio

## About
Master’s engineering student specializing in cybersecurity and defensive security.  
This repository contains hands-on projects demonstrating expertise in network analysis, SOC detection, malware behavior, system hardening, and security automation.  

All projects are conducted in controlled lab environments for educational purposes only.

## Projects

### 1. Network Traffic Analysis (Wireshark)
Objective: Analyze network traffic at the protocol level to understand normal communications and identify patterns that could be abused by attackers.  
Skills Demonstrated: TCP/IP analysis, DNS/HTTP/HTTPS inspection, network protocol behavior, packet-level engineering insights.

### 2. SOC WebDAV Malware Investigation
Objective: Investigate a simulated malware infection delivered via WebDAV using a PCAP file. Reconstruct the attack chain from initial access to command-and-control communication.  
Skills Demonstrated: IDS alert triage, packet analysis (Wireshark), log correlation (Kibana/Zeek), IoC extraction, malware artifact analysis, MITRE ATT&CK mapping, defensive recommendations.  
Tools Used: Security Onion, SNORT (Emerging Threats), SGUIL, Wireshark, Kibana, VirusTotal.

### 3. Malware Network Behavior Analysis
Objective: (To be developed) Analyze network traffic generated by malware to identify command-and-control patterns and behavioral anomalies.  

### 4. Linux Server Hardening
Objective: (To be developed) Apply system hardening techniques to Linux servers, including SSH configuration, firewall rules, and audit logging.  

### 5. Security Automation (Python)
Objective: (To be developed) Automate log analysis, alert generation, and incident reporting using Python scripting.
