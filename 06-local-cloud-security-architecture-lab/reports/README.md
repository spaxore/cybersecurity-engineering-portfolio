# Evidence Reports

This directory stores evidence generated by the local security lab.

| File | Purpose |
|---|---|
| `before-hardening.json` | Trivy report for the intentionally insecure workload. |
| `before-misconfig.json` | Focused misconfiguration report before hardening. |
| `after-hardening.json` | Trivy report for the hardened workload. |

Review all reports before publishing them. Do not commit kubeconfig files, credentials, private keys, personal paths, or other sensitive information. Treat reports as sanitized training evidence, not as proof that all host details have been removed.

Vulnerability counts can remain similar before and after hardening because base-image vulnerabilities are separate from Kubernetes security-context controls. The architecture result is demonstrated through Trivy, OPA, RBAC, NetworkPolicies, and the hardened manifest together.
